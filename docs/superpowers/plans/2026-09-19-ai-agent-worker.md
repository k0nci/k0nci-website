# AI Agent Worker (`k0nci-agent`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy a Cloudflare Worker at `k0nci.me/api/chat` that answers questions about Matej from bundled markdown using Workers AI, streamed as server-sent events.

**Architecture:** A single TypeScript fetch handler validates the request (method, origin, rate limit, body), builds a system prompt from markdown files imported as text modules, and passes the Workers AI stream straight through. Pure functions for validation and prompt building are unit tested with plain Vitest; the handler is tested by calling its `fetch` export with stubbed bindings.

**Tech Stack:** TypeScript, Wrangler 4, Workers AI (`@cf/meta/llama-3.3-70b-instruct-fp8-fast`), Workers rate limiting binding, Vitest 5, ESLint flat config with typescript-eslint, Prettier.

**Spec:** `/Users/konci/Documents/work/k0nci-website/docs/superpowers/specs/2026-09-19-ai-agent-chat-design.md`

- Repo lives at `/Users/konci/Documents/work/k0nci-agent`. All commands below run from there unless stated.
- Node 24, npm. Wrangler is a dev dependency, run via `npx wrangler`.
- Route: exactly `k0nci.me/api/chat`, zone `k0nci.me`.
- Model constant: `@cf/meta/llama-3.3-70b-instruct-fp8-fast`, defined once in `src/index.ts`.
- Limits: max 20 messages, max 1,000 characters per message, roles `user` | `assistant` only, last message must be `user`.
- Rate limit: 10 requests per 60 seconds per client IP, keyed on `CF-Connecting-IP`.
- Errors are JSON `{ "error": string }`; success is `text/event-stream` with `Cache-Control: no-store`. No CORS headers.
- Prettier settings identical to the website: semi, single quotes, width 100, trailing commas es5, LF.

`src/validate.ts`:

```ts
export type ChatRole = 'user' | 'assistant';

export interface ChatMessage {
  role: ChatRole;
  content: string;
}

export const MAX_MESSAGES = 20;
export const MAX_CONTENT_LENGTH = 1000;

export type ValidationResult = { ok: true; messages: ChatMessage[] } | { ok: false; error: string };

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null;
}

function validateMessage(value: unknown, index: number): ChatMessage | string {
  if (!isRecord(value)) return `messages[${index}] must be an object`;
  const { role, content } = value;
  if (role !== 'user' && role !== 'assistant') {
    return `messages[${index}].role must be user or assistant`;
  }
  if (typeof content !== 'string' || content.trim().length === 0) {
    return `messages[${index}].content must be a non-empty string`;
  }
  if (content.length > MAX_CONTENT_LENGTH) {
    return `messages[${index}].content must be at most ${MAX_CONTENT_LENGTH} characters`;
  }
  return { role, content };
}

export function validateChatRequest(body: unknown): ValidationResult {
  if (!isRecord(body)) return { ok: false, error: 'body must be a JSON object' };
  const { messages } = body;
  if (!Array.isArray(messages)) return { ok: false, error: 'messages must be an array' };
  if (messages.length === 0) return { ok: false, error: 'messages must not be empty' };
  if (messages.length > MAX_MESSAGES) {
    return { ok: false, error: `messages must contain at most ${MAX_MESSAGES} items` };
  }

  const validated: ChatMessage[] = [];
  for (const [index, message] of messages.entries()) {
    const result = validateMessage(message, index);
    if (typeof result === 'string') return { ok: false, error: result };
    validated.push(result);
  }

  if (validated[validated.length - 1]?.role !== 'user') {
    return { ok: false, error: 'last message must be from the user' };
  }
  return { ok: true, messages: validated };
}
```

`src/index.ts`:

```ts
import { buildSystemPrompt } from './prompt.ts';
import { validateChatRequest } from './validate.ts';

export const MODEL = '@cf/meta/llama-3.3-70b-instruct-fp8-fast';
const CHAT_PATH = '/api/chat';

function jsonError(status: number, error: string, headers: HeadersInit = {}): Response {
  return new Response(JSON.stringify({ error }), {
    status,
    headers: { 'Content-Type': 'application/json', 'Cache-Control': 'no-store', ...headers },
  });
}

export default {
  async fetch(request, env): Promise<Response> {
    if (request.method !== 'POST') return jsonError(405, 'method not allowed', { Allow: 'POST' });
    if (new URL(request.url).pathname !== CHAT_PATH) return jsonError(404, 'not found');
    if (request.headers.get('Origin') !== env.ALLOWED_ORIGIN) return jsonError(403, 'forbidden');

    const ip = request.headers.get('CF-Connecting-IP') ?? 'unknown';
    const { success } = await env.RATE_LIMITER.limit({ key: ip });
    if (!success) return jsonError(429, 'too many requests');

    let body: unknown;
    try {
      body = await request.json();
    } catch {
      return jsonError(400, 'body must be valid JSON');
    }
    const validation = validateChatRequest(body);
    if (!validation.ok) return jsonError(400, validation.error);

    let result: unknown;
    try {
      result = await env.AI.run(MODEL, {
        messages: [{ role: 'system', content: buildSystemPrompt() }, ...validation.messages],
        stream: true,
      });
    } catch (error) {
      console.error('Workers AI call failed', error);
      return jsonError(502, 'model unavailable');
    }
    if (!(result instanceof ReadableStream)) return jsonError(502, 'model unavailable');

    return new Response(result, {
      headers: { 'Content-Type': 'text/event-stream', 'Cache-Control': 'no-store' },
    });
  },
} satisfies ExportedHandler<Env>;
```

If `tsc` rejects the `MODEL` string as not a member of the Workers AI model union, keep the constant as is and change the call to `env.AI.run(MODEL as Parameters<Ai['run']>[0], ...)`. Do not loosen anything else.

Cloudflare Worker behind `POST https://k0nci.me/api/chat`. It answers questions about Matej

## API

Request:

```json
{ "messages": [{ "role": "user", "content": "What does Matej do?" }] }
```

Rules: roles `user` or `assistant` only, last message from the user, at most 20 messages of at
most 1,000 characters. Requests must carry the site `Origin`; each IP gets 10 requests per minute.

Response: `text/event-stream`, events `data: {"response": "<token>"}` ending with `data: [DONE]`.
Errors are JSON `{ "error": "..." }` with status 400, 403, 404, 405, 429 or 502.
